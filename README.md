# Transcribe Helper

A practice tool for learning music by ear: slow a song down without changing its pitch, loop the bit you're working on, and pick the part you're after out of the mix. For macOS and Linux.

**Website and downloads: [transcribe.leepatrickfreeman.dev](https://transcribe.leepatrickfreeman.dev)**

This repository holds the app's releases only. Download the latest build from the
[releases page](https://github.com/leefreemanxyz/transcribe-helper-releases/releases/latest):

- `Transcribe-Helper.dmg`: macOS (Apple silicon and Intel)
- `Transcribe-Helper_amd64.deb`: Debian and Ubuntu
- `Transcribe-Helper.x86_64.rpm`: Fedora

Found a bug or want a feature? [Open an issue](https://github.com/leefreemanxyz/transcribe-helper-releases/issues).
