# By Ear

A practice tool for learning music by ear: slow a song down without changing its pitch, loop the bit you're working on, and pick the part you're after out of the mix. For macOS, Windows (beta) and Linux.

**Website and downloads: [transcribe.leepatrickfreeman.dev](https://transcribe.leepatrickfreeman.dev)**

By Ear was called Transcribe Helper until v0.11; older releases here use that name.

This repository holds the app's releases only. Download the latest build from the
[releases page](https://github.com/leefreemanxyz/transcribe-helper-releases/releases/latest):

- `ByEar.dmg`: macOS (Apple silicon and Intel)
- `ByEar-setup.exe`: Windows (beta)
- `ByEar_amd64.deb`: Debian and Ubuntu
- `ByEar.x86_64.rpm`: Fedora
- `ByEar_amd64.AppImage`: other Linux distributions

Found a bug or want a feature? [Open an issue](https://github.com/leefreemanxyz/transcribe-helper-releases/issues).
